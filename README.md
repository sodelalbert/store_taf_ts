## Configuration

`playwright.config.ts` contains the configuration settings for the Playwright tests.

## Run Tests

To run the tests for the `store_taf_ts` package, you can use the following command:

```bash
npx playwright test
```

After executing the tests, a report will be generated in the `playwright-report` directory. You can view the report by opening the `index.html` file in a web browser.

```bash
npx playwright show-report
```
